# DIY: Raspberry Pi + AMOLED Display vs Tablet

## Cost Estimate (Raspberry Pi route)

| Component | Source | Est. price (PLN) |
|---|---|---|
| Raspberry Pi 5 (4GB) | botland.pl / kamami.pl | ~300 |
| 10.5" AMOLED touchscreen (Waveshare HDMI) | Allegro / AliExpress | ~700–900 |
| MicroSD 32GB | anywhere | ~40 |
| Official RPi power supply | botland.pl | ~60 |
| Case/stand for the display | varies | ~50–100 |
| **Total** | | **~1,150–1,400** |

## Why the Tablet Wins for Table-Top Use

The RPi + display setup ends up costing roughly the same as a refurbished Samsung Tab S7+, but delivers a worse result:

- **Display quality**: Waveshare AMOLED is a bare panel in a generic metal frame — not as refined or well-calibrated as a Samsung AMOLED
- **Cables**: two separate power cables (RPi + display) plus HDMI between them — hard to hide on a table
- **No battery**: permanently wall-tethered
- **Aesthetics**: looks like a DIY project, not a frame
- **Setup effort**: significantly more work than installing an Android app

## When RPi + Display Makes Sense

- **Wall-mounted installation** where cables can be hidden inside the wall
- You already have a spare monitor
- You want a much larger display (24"+) at low cost

## Conclusion

For a table-top photo frame, a tablet is the better choice — same price range, better display, single power cable, cleaner result. The RPi route is worth considering only if wall-mounting with hidden cables.
